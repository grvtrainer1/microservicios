Flujo 1 Buscar Libros en Catálogo 

sequenceDiagram
    autonumber
    actor U as "Usuario (React)"
    participant G as "Gateway (:8080)"
    participant E as "Eureka (:8761)"
    participant B as "MS-Buscador (:8082)"
    participant DB_B as "BD Buscador (H2)"

    U->>G: GET /api/libros?titulo=Quijote
    G->>E: Resuelve IP de ms-buscador
    E-->>G: Instancia IP:8082
    G->>B: GET /libros?titulo=Quijote (StripPrefix=1)
    B->>DB_B: SELECT * FROM libros WHERE titulo LIKE '%Quijote%'
    DB_B-->>B: Lista de libros
    B-->>G: 200 OK [ id: 1, disponible: true ]
    G-->>U: 200 OK

Flujo 2 Crear Préstamo (Validación y Cambio de Estado) 

sequenceDiagram
    autonumber
    actor U as "Usuario (React)"
    participant G as "Gateway (:8080)"
    participant E as "Eureka (:8761)"
    participant O as "MS-Operador (:8081)"
    participant B as "MS-Buscador (:8082)"
    participant DB_O as "BD Operador (H2)"
    participant DB_B as "BD Buscador (H2)"

    U->>G: POST /api/prestamos { libroId: 3, usuario: 'ana' }
    G->>E: Resuelve IP de ms-operador
    E-->>G: Instancia IP:8081
    G->>O: POST /prestamos
    Note over O,B: Consulta directa por nombre Eureka (http://ms-buscador/...)
    O->>B: GET /libros/3
    B->>DB_B: SELECT * FROM libros WHERE id=3
    DB_B-->>B: { id: 3, disponible: true }
    B-->>O: 200 OK (disponible: true)
    
    alt Libro Disponible
        O->>DB_O: INSERT INTO prestamos (libro_id, estado='ACTIVO')
        DB_O-->>O: Guardado (id: 1)
        O->>B: PUT /libros/3/disponibilidad { disponible: false }
        B->>DB_B: UPDATE libros SET disponible=false
        DB_B-->>B: Actualizado
        B-->>O: 200 OK
        O-->>G: 201 Created { id: 1, estado: 'ACTIVO' }
        G-->>U: 201 Created
    else Libro NO Disponible
        O-->>G: 409 Conflict (Libro prestado)
        G-->>U: 409 Conflict
    end

Flujo 3 Devolver Libro (Restablecer Disponibilidad) 

sequenceDiagram
    autonumber
    actor U as "Usuario (React)"
    participant G as "Gateway (:8080)"
    participant E as "Eureka (:8761)"
    participant O as "MS-Operador (:8081)"
    participant B as "MS-Buscador (:8082)"
    participant DB_O as "BD Operador (H2)"
    participant DB_B as "BD Buscador (H2)"

    U->>G: PUT /api/prestamos/1
    G->>E: Resuelve IP de ms-operador
    E-->>G: Instancia IP:8081
    G->>O: PUT /prestamos/1
    O->>DB_O: UPDATE prestamos SET estado='DEVUELTO' WHERE id=1
    DB_O-->>O: OK
    O->>B: PUT /libros/3/disponibilidad { disponible: true }
    B->>DB_B: UPDATE libros SET disponible=true
    DB_B-->>B: OK
    B-->>O: 200 OK
    O-->>G: 200 OK { id: 1, estado: 'DEVUELTO' }
    G-->>U: 200 OK

Reglas Clave y Endpoints REST API

Frontend Aislado

El Frontend en React solo se comunica con el Gateway (:8080). Nunca conoce las IPs ni los puertos reales de los microservicios.

Descubrimiento Dinámico

Todas las llamadas inter-servicio utilizan nombres registrados en Eureka (http://ms-buscador/...) con balanceo de carga implícito.

Servicio Método Ruta Gateway Ruta Interna Descripción / Ámbito
ms-buscador GET /api/libros /libros Buscar catálogo (filtros opcionales: ?titulo, ?autor, ?anio, ?disponible)
ms-buscador GET /api/libros/{id} /libros/{id} Obtener ficha técnica de un libro por ID
ms-buscador POST /api/libros /libros Registrar un nuevo libro en el catálogo
ms-buscador PUT N/A (Interno) /libros/{id}/disponibilidad Actualizar estado disponible (true/false) — Invocado internamente por ms-operador
ms-operador GET /api/prestamos /prestamos Obtener todos los préstamos registrados
ms-operador GET /api/prestamos/{id} /prestamos/{id} Obtener información de un préstamo por ID
ms-operador POST /api/prestamos /prestamos Valida disponibilidad en ms-buscador y crea un nuevo préstamo
ms-operador PUT /api/prestamos/{id} /prestamos/{id} Devolver préstamo (marca estado DEVUELTO y restablece libro a disponible=true)
eureka-server GET N/A (Interno) /eureka/apps Registro y descubrimiento de instancias de microservicios activas
